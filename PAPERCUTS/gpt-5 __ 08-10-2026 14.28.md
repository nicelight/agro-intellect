# Papercuts

- A repository search command included an absent root `package.json` alongside existing paths, so `rg` returned a noisy `No such file or directory` diagnostic even though the useful search results were still available. Check optional paths before passing them to a multi-path search.
- A collaboration wait was first called with `1000 ms`, below the tool's documented `10000 ms` minimum, producing an avoidable validation failure. Use the declared minimum for quick polls.
- The project virtualenv does not include the optional `jsonschema` package, so an attempted standalone Draft 2020-12 validation failed before reading the cards. Use the repository's built-in task-record validator unless an external schema validator is already declared by the project.
- A read command assumed EP-006 had a dataset-specific filename, so `sed` stopped before reading the remaining requested files. Resolve linked artifact paths from the router before composing strict `&&` read chains.
