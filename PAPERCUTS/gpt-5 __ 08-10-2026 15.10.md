# Papercuts

- A mechanically transformed `apply_patch` changed both the replacement text
  and its expected context, so patch verification failed. Keep patch context
  literal and transform only the intended replacement before calling the tool.
- A large documentation patch used a visually reconstructed wrapped sentence
  as context and failed on the file's actual line wrapping. Inspect narrow
  ranges first and patch independent hunks with literal local context.
- The first post-rebuild lint found that `clarification_status: complete`
  mechanically requires a `## Clarifications` block in the feature document.
  Add the feature-local durable entry in the same `/feature-doctor` patch as
  the metadata, not only in the separate clarification protocol.
- A consistency-search command embedded Markdown backticks in a double-quoted
  shell argument, so command substitution ran and polluted the search output.
  Use a single-quoted shell pattern or omit backticks from `rg` patterns.
- A quick index query assumed the task index root was an array; the repository
  shape is `{version, tasks}`. Query `.tasks[]` directly in queue checks.
