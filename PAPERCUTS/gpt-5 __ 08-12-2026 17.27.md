# Papercuts

- Preferred-context search included the optional `.memory-bank/guides` path even though that directory is absent, so `rg` emitted a distracting `No such file or directory` warning before returning otherwise valid discovery results.
- The project `.venv` lacks `jsonschema`, so the direct Draft 2020-12 validation probe could not run even though `node scripts/mb-lint.mjs` independently validated the task records; a documented project-native single-card schema command would make this check less ambiguous.
- A multi-file `rg -o` traceability probe retained filename prefixes, so its
  shell loop treated `<path>:REQ-020` as the identifier and reported a false
  missing-REQ failure; `--no-filename` is required for token-only loop input.
