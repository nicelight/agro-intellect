# Papercuts

- Combining several complete governing documents or task records into one tool
  result silently exceeded the output budget and truncated the middle of the
  review context. Read large inputs in bounded per-file or small-group calls so
  the required full-read contract remains auditable.
- A quick task-dependency probe assumed the field name `dependencies`, while
  the canonical task schema uses `depends_on`; the resulting `jq` failure was
  avoidable by inspecting one card's keys first.
