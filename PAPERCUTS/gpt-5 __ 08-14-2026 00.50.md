# Papercuts

- `wait_agent` rejected a short non-blocking poll because its documented minimum timeout is 10000 ms; callers must use at least that value even for an immediate status check.
- `node scripts/mb-doctor.mjs --json` reported 68 warnings in its summary but emitted a JSON document truncated near 64 KiB because the reporter calls `process.exit(...)` immediately after `console.log`; downstream `jq` therefore failed with `Unfinished string at EOF`. The shorter text report remained complete and usable for aggregation.
- A diagnostic cleanup command targeting a file created by `mktemp` was rejected solely because it contained `rm -f`; the command policy did not distinguish the explicit temporary-file target from unsafe broad deletion.
